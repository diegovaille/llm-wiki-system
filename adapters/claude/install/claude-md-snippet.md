## Wiki

Project knowledge lives at `~/Git/wiki/<project>/`.

- `/wiki-query` — search compiled knowledge for this project
- `/wiki-capture` — distill a session learning into one canonical change (noop/update/create)
- `/wiki-review` — see pending staged items
- `/wiki-promote <path>` — apply a proposed staged file

Start-of-session orientation: `~/Git/wiki/<project>/views/index.md` — read it when wiki-relevant work begins.

Never edit `~/Git/wiki/<project>/pages/*.md` or `views/*.md` directly.
